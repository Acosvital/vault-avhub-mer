# Quem Faz o Quê

Lista de todos os setores e funções que participam do ciclo de vida de um pedido, do início ao fim, com a responsabilidade de cada um.

| Setor | O que faz no processo |
|---|---|
| **Vendas (Vendedor)** | Emite o pedido, decide se a Qualidade deve acompanhar o item desde o início ou só no fim, acompanha o status do pedido |
| **PCP** | Organiza a carteira do pedido, classifica cada item (de onde vem e se já está disponível), aciona compras, inicia fabricações, decide o que fazer quando um item é reprovado |
| **Compras (Comprador)** | Escolhe o fornecedor, negocia preço e condições, fecha a compra, define se o material chega pronto ou se ainda precisa de um trabalho extra |
| **CCP (acompanhamento de compras)** | Faz o acompanhamento ativo do prazo de entrega das compras já fechadas, cobrando o fornecedor quando necessário |
| **Aprovador / Diretoria** | Dá uma segunda aprovação em compras acima de um valor de referência |
| **Fornecedor** | Entrega o material comprado; não tem acesso ao sistema da empresa — todo contato é feito por telefone, e-mail ou WhatsApp |
| **Logística de entrada** | Busca o material no fornecedor quando a compra é do tipo em que a empresa mesmo retira (veja [[Comprando-o-que-Falta]]) |
| **Recebimento (Almoxarifado)** | Confere o material que chega, pesa, identifica o lote, etiqueta |
| **Qualidade** | Inspeciona os itens (no início ou no fim do processo), aprova ou reprova, registra o motivo de uma reprovação |
| **Fábrica / Setores de produção** | Executa o corte, ajuste ou fabricação de um item, passo a passo, até ele ficar pronto |
| **Estoque (Almoxarife)** | Guarda o saldo disponível, separa os itens já prontos, cuida da movimentação entre depósitos |
| **Expedição** | Embala, organiza a carga e prepara o despacho |
| **Logística de saída** | Cuida do transporte final até o cliente |
| **Fiscal** | Emite a nota fiscal (sempre pelo sistema comercial) |

## Um ponto de atenção

Alguns dos nomes acima são um setor dentro do fluxo do pedido; outros são um perfil de acesso ao sistema, que pode acumular mais de uma função. Por exemplo, "Almoxarife" é o perfil que pode operar tanto o Recebimento quanto o Estoque — não é uma etapa separada, é uma pessoa que atua em mais de uma etapa.
